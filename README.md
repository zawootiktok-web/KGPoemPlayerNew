# KG တေးကဗျာ Player 2.0

**KG တေးကဗျာ Player** သည် Android 6.0 (API 23) နှင့်အထက်တွင် အသုံးပြုနိုင်သည့် ကလေးတေးကဗျာအသံဖွင့်နှင့် Karaoke အက်ပ်ဖြစ်သည်။ မူရင်း project ကို maintainable Java architecture ဖြင့် ပြန်လည်ရေးသားထားပြီး တေးကဗျာအမည်အမှန်များ၊ အလိုအလျောက်ဆက်တိုက်ဖွင့်ခြင်း၊ စာသားအပြည့်အစုံပါဝင်သည့် Karaoke မျက်နှာပြင်နှင့် background playback controls များကို ထည့်သွင်းထားသည်။

## အဓိကပြင်ဆင်မှုများ

| အပိုင်း | လုပ်ဆောင်ချက် |
|---|---|
| တေးကဗျာစာရင်း | Transcript metadata မှ တေးကဗျာအမည် ၆၃ ပုဒ်လုံးကို အလိုအလျောက်ဖတ်ပြီး စာရင်းတွင် ပြသသည်။ |
| ဆက်တိုက်ဖွင့်ခြင်း | ရွေးထားသည့်တေးကဗျာပြီးပါက နောက်တစ်ပုဒ်ကို အလိုအလျောက်ဖွင့်သည်။ အရင်၊ ခဏရပ်/ဆက်ဖွင့်နှင့် နောက် controls ပါဝင်သည်။ |
| Background playback | Foreground service နှင့် Android notification controls အသုံးပြုထားသောကြောင့် app ကို နောက်ခံထားသော်လည်း ဆက်လက်ဖွင့်နိုင်သည်။ |
| Karaoke | စာသားအားလုံးကို scrolling list အဖြစ် ပြသပြီး လက်ရှိဆိုရမည့်စာကြောင်းကို highlight လုပ်သည်။ Seek bar၊ အရင်/နောက်တစ်ပုဒ်နှင့် auto-next ပါဝင်သည်။ |
| ရှာဖွေခြင်း | တေးကဗျာအမည် သို့မဟုတ် အမှတ်ဖြင့် ရှာနိုင်သည်။ |
| အကြိုက်ဆုံး | အကြိုက်ဆုံးတေးကဗျာများကို device ပေါ်တွင် သိမ်းဆည်းပြီး filter လုပ်နိုင်သည်။ |
| Content validation | အသံ၊ JSON နှင့် TXT အရေအတွက်ကို ၆၃ စုံစီဖြစ်ကြောင်းနှင့် lyric timings များ audio duration အတွင်းရှိကြောင်း audit tool ဖြင့် စစ်ဆေးသည်။ |

## Project structure

| Path | တာဝန် |
|---|---|
| `PoemRepository.java` | တေးကဗျာ ၆၃ ပုဒ်၏ အသံနှင့် metadata တစ်နေရာတည်းမှ စီမံခြင်း |
| `PlaybackService.java` | Foreground audio playback၊ audio focus၊ queue နှင့် notification controls |
| `MainActivity.java` | စာရင်း၊ ရှာဖွေမှု၊ favorites နှင့် mini-player |
| `KaraokeActivity.java` | Karaoke အသံ၊ seek၊ auto-next နှင့် active lyric synchronization |
| `KaraokeAdapter.java` | စာသားအားလုံးနှင့် active-line highlighting |
| `assets/transcripts/` | တေးကဗျာတစ်ပုဒ်စီ၏ title၊ lyrics နှင့် timing JSON |
| `tools/audit_content.py` | အသံ/စာသား coverage နှင့် timing validation |
| `tools/repair_content.py` | Content correction များကို reproducible ပုံစံဖြင့် ပြန်တည်ဆောက်ခြင်း |

## Build နှင့် စစ်ဆေးခြင်း

Project သည် **Java 17**, **Gradle 8.7**, **Android Gradle Plugin 8.6.1** နှင့် **compileSdk 35** ကို အသုံးပြုသည်။ Android SDK path ကို `local.properties` တွင် မိမိစက်နှင့်ကိုက်ညီအောင် ပြင်ပြီး အောက်ပါ command များကို run နိုင်သည်။

```bash
python3 tools/audit_content.py
./gradlew clean testDebugUnitTest lintDebug assembleDebug
```

အောင်မြင်ပါက APK ကို `app/build/outputs/apk/debug/app-debug.apk` တွင် ရရှိမည်။

## Content note

ပေးပို့ထားသည့် transcript အများစုသည် မူရင်း project ထဲက OCR/audio-derived draft များဖြစ်သည်။ Application အတွင်း စာသားအားလုံးကို ဖော်ပြနိုင်အောင် data coverage နှင့် timing bounds များကို ပြုပြင်ထားပြီး ၅၈၊ ၅၉၊ ၆၀ နှင့် ၆၃ တို့၏ မပြည့်စုံသောစာသားများကို bundled audio ဖြင့် ပြန်လည်ဖြည့်စွက်ထားသည်။ Public release မတိုင်မီ စာလုံးပေါင်းနှင့် အဆိုအတိအကျကို မူရင်းစာအုပ် သို့မဟုတ် တေးရေးသူ၏စာမူနှင့် editorial proofreading တစ်ကြိမ် ထပ်မံတိုက်ဆိုင်ရန် အကြံပြုသည်။
